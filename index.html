Awaab's Law Triage Platform — statutory housing compliance

2026

Architect & Lead Engineer

A resident-first hazard reporting and compliance platform for social landlords under the Social Housing (Awaab's Law) Regulations 2025. .NET 10 modular monolith in vertical slices with an Angular 22 zoneless client, PostgreSQL on Neon and Cloudflare R2 evidence storage. Models seven distinct statutory clocks from a recorded awareness timestamp (injected TimeProvider, never DateTime.UtcNow), the full HHSRS hazard taxonomy, append-only auditing and short-lived signed evidence URLs. Tenant isolation is enforced three ways — EF Core query filters, a SaveChanges interceptor and PostgreSQL row-level security — with special-category health data kept out of logs and traces. Twenty-eight ADRs record every load-bearing decision; xUnit unit, integration, architecture and Playwright end-to-end tests. Live: app.statutoryclock.co.uk

OT Plant Designer (Phoenix) — IEC 62443 zones & conduits

2026

Architect & Lead Engineer

A CAD-style designer for operational-technology plants where the drawing is the source of truth: components are symbols with typed ports, communication lines are drawn port to port, and a component's IEC 62443 zone is derived from where its symbol sits. Built a TypeScript pnpm monorepo — a typed component model with generated JSON and ids, a pure validator implementing VR-01 to VR-16, report generators for per-conduit firewall rules and zone/conduit reports, a React + Vite designer with undoable edits and orthogonal routing, and a framework-free API with append-only drawing revisions, magic-link auth and role-scoped access. PostgreSQL on Neon in production, PGlite in tests; Playwright end-to-end suite; in-app help with generated Quick Start and User Manual PDFs. Live: phoenixdemo.online

Jamaica Public Accountability Platform (Babylon)

2026

Architect & Lead Engineer

A mobile-first platform where people report misconduct by police and public officials, corroborate each other's reports and see how well each report is verified. Rebuilt from a Flask/OpenOversight base in Next.js 16, React 19, Tailwind CSS 4 and PostgreSQL (Drizzle). Five-step phone report flow with offline drafts and a send queue; EXIF, GPS and device metadata stripped from evidence; anonymous by default. A verification state machine with an audit log, weighted corroboration (confirmed member 1, anonymous 0.25, account created after the report 0.5), a published scoring formula and anti-gaming rules; per-parish dashboards and ZIP escalation packages with a SHA-256 manifest. SMS and WhatsApp intake, PWA service worker, 125 tests. Live (private beta): babyloncheck.com

SaraMP / OurPatch — constituency issue tracker

2026

Architect & Lead Engineer

A multi-tenant, map-first issue tracker for an MP's constituency office: a postcode resolves to a constituency and its MP, and the map, issue list and staff console are all scoped to that tenant. Built with a zero-dependency Node 22 server and node:sqlite — no install step — plus a MapLibre front end. The privacy model is the engineering: every submission is a private Report, and only place-based categories become a structured public entry with no free text, names or exact address; public coordinates carry deterministic 45–130 m jitter and only the postcode district is ever shown. Staff promote, merge, hide and publish with a full audit log; tenant-scoped session cookies. Runs with npm start on Node 22, with Docker and Fly.io deployment (persistent volume).
